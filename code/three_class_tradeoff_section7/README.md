# Section 7: Three-Class Space-Time Trade-Off (Figures 10 & 11)

This subproject implements and reproduces the experiments, mathematical theorems, and visual results for **Section 7: Three-Class Space-Time Trade-Off (Figures 10 & 11)** from the foundational paper:
> **"Bitmap Index Design and Evaluation"** — Chee-Yong Chan & Yannis E. Ioannidis (ACM SIGMOD 1998).

---

```text
three_class_tradeoff_section7/
```

## 🚀 Execution

To execute the simulation and regenerate all output plots and datasets:

```bash
python code/three_class_tradeoff_section7/code/three_class_tradeoff_simulation.py
```
