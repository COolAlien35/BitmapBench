# Section 6: Extremal Indexes & Theorem 6.1 Monotonicity

This subproject implements and reproduces the experiments, mathematical theorems, and visual results for **Section 6: Extremal Indexes & Theorem 6.1 Monotonicity** from the foundational paper:
> **"Bitmap Index Design and Evaluation"** — Chee-Yong Chan & Yannis E. Ioannidis (ACM SIGMOD 1998).

---

## 📁 Directory Structure

```text
extremal_indexes_section6/
├── README.md
├── code/
│   ├── extremal_points_and_monotonicity_simulation.py
└── results/
    ├── theorem6_1_space_time_monotonicity.png
    ├── extremal_points_on_pareto_frontier.png
    ├── theorem6_1_analytical_vs_empirical_verification.png
    ├── extremal_indexes_comprehensive_data.csv
```

---

## 🚀 Execution

To execute the simulation and regenerate all output plots and datasets:

```bash
python code/extremal_indexes_section6/code/extremal_points_and_monotonicity_simulation.py
```
